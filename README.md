# JMComic 阅读器 · BJTU MIS 插件

`JMComic 阅读器` 是运行在 **BJTU MIS 1.4.0 及以上版本**中的第三方静态插件。它采用 Manifest v3 / `contract_v1`，提供匿名浏览、阅读与本地离线管理能力；当前插件版本为 `2.0.2`。

> 本插件可能展示成人漫画内容，仅限年满 18 周岁的用户使用。它是非官方第三方项目，与 JMComic 和 BJTU MIS 官方均无隶属关系。请遵守所在地法律、内容版权和上游站点规则。

## 功能

- 匿名发现与搜索：支持分类浏览、排序、时间筛选，以及编号、作品、作者、标签和角色搜索。
- 漫画详情与阅读：查看章节、标签、作品、角色和相关推荐；支持横向逐页、纵向滚动、章节切换和自动续读。
- 本地资料库：收藏、收藏分组、备注、搜索记录、阅读历史和阅读进度都保存在当前插件沙箱内。
- 受控离线缓存：可下载整本或当前章节，任务支持暂停、恢复、取消和删除；离线时只展示已缓存内容。
- 存储管理：可设置临时图片缓存上限，固定下载不计入临时缓存配额，并可一键清理临时缓存。
- 元数据备份：可生成带 SHA-256 校验的 `JMCR1` 文本备份，支持预览、按更新时间合并或完整替换。备份包含收藏、分组、备注、历史、进度和设置，不包含图片、下载队列或成年确认状态。

## 隐私与权限

插件仅请求以下 BJTU MIS 能力：运行时生命周期、受控网络请求、KV 存储、Blob 存储和资源缓存。请求只会发送至清单中声明的 JM API/CDN 域名；上游出现未声明的新域名时，插件会提示更新，而不会绕过宿主的来源白名单。

插件不读取 BJTU 身份信息、课表、成绩、校园凭据或其他校园数据；不提供 JM 账号登录、云收藏、评论、遥测、代理后端或系统下载目录导出功能。所有收藏、进度与缓存均由 BJTU MIS 按发布者与插件 ID 隔离保存。

## 安装与使用

1. 使用 BJTU MIS `1.4.0` 或更新版本。
2. 在插件大厅安装本插件；在审核或更新尚未可用时，也可通过“高级 / 开发者导入”填写仓库地址：`https://github.com/wan300/JMComic-Crawler-Python`。
3. 安装时核对插件 ID 为 `io.github.wan300.jmcomic`，并按宿主界面确认所需的受控网络与本地存储授权。
4. 首次启动时确认已年满 18 周岁，然后即可开始匿名浏览和阅读。

插件依赖上游匿名 API 和已声明的线路，站点协议、可用域名或网络环境变化时，搜索、详情或图片加载可能不可用，需要等待插件更新。

## 开发与校验

插件源码位于 [`plugin/`](plugin)，构建后的静态安装包位于 [`dist/`](dist)。根目录中的 Python 包是原项目保留的源码，不参与 BJTU MIS 插件运行时。

```powershell
npm ci
npm test
npm run typecheck
npm run build
npm run check:dist
npm run check:package
```

`npm run build` 会重新生成 `dist/`。CI 还会使用固定版本的 BJTU MIS 官方工具执行源码与市场元数据检查、浏览器回归测试、包检查和确定性打包验证。更详细的宿主兼容性、Mock Host 与官方 CLI 使用方式见 [`plugin/README.md`](plugin/README.md)。
